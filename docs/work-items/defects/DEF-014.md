## Cause

- Section 6 of the contract gives each folder of an installed runtime the mode 0755.
- The unpack sets 0755 on each folder that it makes inside the unpack folder (`open_dir` in `crates/daemon/src/model/unpack.rs`).
- The unpack folder itself is made by `tempfile` in `unpack_folder` (`crates/daemon/src/model/install.rs`) and renamed to `<version>-<backend>/`, with no change of its mode. Its mode is 0777 less the umask of the daemon: 0775 under `umask 0002`, 0700 under `umask 0077`.
- The parent folders are 0700, so no other account could use the group write bit. The mode was wrong, not open.

## Correction

On the branch `fix/model-release-folder-mode`:

- [x] `unpack_folder` sets 0755 on the unpack folder when it makes it, before the unpack and the rename.
- [x] An integration test installs an archive under `umask 0077` and reads 0755 on the release folder (it fails without the correction: 0700).
